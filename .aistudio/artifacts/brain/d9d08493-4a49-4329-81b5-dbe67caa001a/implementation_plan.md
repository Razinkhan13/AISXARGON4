# Implementation Plan: 100% Free & Open-Source Architecture

Transition the AIS Enterprise Systems Obsidian Cockpit into a 100% free-to-use, zero-cost, fully self-contained application with client-side IndexedDB persistence, deterministic zero-quota AI engines, and locally bundled open-source assets.

---

## 1. Core Architecture & Strategy

### A. Client-Side Persistence Layer (Zero Server Cost)
- **Primary Storage**: Browser **IndexedDB** database (`AIS_COCKPIT_DB`) with dedicated object stores:
  - `transactions`: Deal pipeline, fund reconciliation states, and timestamps.
  - `leads`: 24 Bangladeshi developer and e-commerce targets with contact info, customized hooks, and outreach statuses.
  - `invoices`: Statutory Mushak-6.3 tax records and VAT receipts.
  - `vault_docs`: Saved contracts, board resolutions, and SOW templates.
- **Fail-Safe Fallback**: Automatic synchronization with `localStorage` for backwards compatibility.
- **Data Portability**: Built-in 1-click **JSON Backup & Restore** utility allowing users to export all records and import them on any machine without database provisioning or hosting fees.

### B. Deterministic Client-Side AI & Algorithmic Engines (Zero API Cost)
- **Lead Pitch Engine**: In-memory deterministic pitch generator combining deal metadata, developer inventory (e.g. Sheltech Archadia, Shanta Pinnacle, bti Celebration Point), and customized bilingual Bangla/English closing scripts without external LLM API keys.
- **3-Second COD Fraud & RTO Calculator**: Algorithmic scoring model evaluating customer order parameters, phone prefix legitimacy, delivery district distance, and order velocity to compute risk scores (0–100%) and courier burn protection without token costs.
- **38-Second Concierge Simulator**: Client-side interactive WhatsApp conversational state machine with step-by-step buyer journeys, floor plan reveals, and simulated bKash/Trust Bank deposit locks.

### C. Fully Self-Hosted & Local Open-Source Bundling
- **Eliminate CDN Script Dependencies**:
  - Replace `https://cdn.tailwindcss.com/3.4.17` with the locally compiled Tailwind CSS bundle generated by Vite.
  - Download and bundle `html2pdf.bundle.min.js` directly into `/public/html2pdf.bundle.js` for standalone PDF generation.
  - Maintain local bundles for `/public/qrcode.bundle.js` and `/public/jsqr.bundle.js`.
- **System Monospace & High-Contrast Typography**: Utilize system typography stacks (`ui-sans-serif`, `system-ui`, `ui-monospace`, `Menlo`, `Consolas`) to render zero-latency interfaces without external Google Fonts dependencies.

## 3. Verification & Quality Assurance Plan

### Automated Checks:
- Run `npm run build` (`compile_applet`) to ensure clean bundling with Vite and TypeScript.
- Run `tsc --noEmit` (`lint_applet`) to ensure strict type compliance.
- Audit `dist/index.html` to confirm zero external CDN scripts and 100% matched DOM element IDs.

### Manual Verification Scenarios:
1. **Offline Independence Test**: Disconnect network/simulate offline mode; verify all 7 tabs, calculators, and camera QR scanner operate without network requests.
2. **Persistence Test**: Approve a transaction, reload the browser, and confirm the Recharts chart, progression bar, and transaction queue retain state from IndexedDB.
3. **Data Backup Test**: Export a JSON backup, modify transactions, and restore the backup to confirm integrity.
